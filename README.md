# 🎮 Tic-Tac-Toe Pro

A modern, responsive, and feature-rich Tic-Tac-Toe web application built with vanilla HTML5, CSS3, and JavaScript.

## ✨ Features

- **🎮 Dual Game Modes**:
  - **👥 2 Players**: Local Pass & Play mode.
  - **🤖 vs AI**: Play against an intelligent computer opponent.
- **🧠 3 AI Difficulties**:
  - **Easy**: Casual & randomized moves.
  - **Medium**: Balanced tactical play.
  - **Impossible**: Unbeatable AI powered by the **Minimax Algorithm** with Alpha-Beta pruning.
- **📊 Live Scoreboard**: Tracks Player X wins, Player O / AI wins, and Draws across rounds.
- **🔊 Built-in Web Audio SFX**: Pure synthesized audio feedback (moves, wins, ties, button clicks) with a mute toggle — zero external audio dependencies.
- **✨ Visual Polish**:
  - Dark glassmorphism interface with glowing neon accents (Cyan for X, Pink for O).
  - Hover ghost preview of the active player's symbol.
  - Glowing pulse animation on the winning three tiles.
  - Lightweight celebration canvas confetti on victory.
  - Animated victory and draw modals.
- **📱 Fully Responsive**: Fluid design optimized for desktops, tablets, and mobile smartphones.

## 🚀 Getting Started

Simply open `tictactoe.html` in any modern web browser:

```bash
# Open directly or via a local server
open tictactoe.html
# or with python:
python3 -m http.server 8000
```
